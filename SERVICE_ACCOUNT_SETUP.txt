# Google Drive Service Account Setup

This guide shows how to set up automatic Google Drive access using a Service Account instead of OAuth.

## Step 1: Create Service Account

1. Go to [Google Cloud Console](https://console.cloud.google.com)
2. Select your project
3. Go to **IAM & Admin** → **Service Accounts**
4. Click **Create Service Account**
5. Name: `drive-service-account`
6. Grant roles: **Editor** (or more specific Drive roles)
7. Click **Done**

## Step 2: Create Service Account Key

1. Click on your new service account
2. Go to **Keys** tab
3. Click **Add Key** → **Create new key**
4. Choose **JSON** format
5. Download the `.json` file (keep it secure!)

## Step 3: Share Drive Files/Folders

For the service account to access files, you need to share them:

1. Go to your Google Drive
2. Right-click on files/folders you want to share
3. Click **Share**
4. Add the service account email (found in the JSON file as `client_email`)
5. Give appropriate permissions (Viewer/Editor)

## Step 4: Update Environment Variables

Update your `.env` file:

```env
# Remove OAuth credentials
# GOOGLE_CLIENT_ID=...
# GOOGLE_CLIENT_SECRET=...

# Add service account path
GOOGLE_SERVICE_ACCOUNT_KEY_PATH=./service-account-key.json

# Optional: Specify a specific Drive folder ID
GOOGLE_DRIVE_FOLDER_ID=your-folder-id-here
```

## Step 5: Rename Service Account Key

Move your downloaded JSON file to the project root and rename it:

```bash
mv ~/Downloads/project-name-123456-abcdef123456.json ./service-account-key.json
```

**⚠️ Security Warning:** Never commit this file to version control!

## Step 6: Update .gitignore

Add to `.gitignore`:

```
service-account-key.json
*.pem
```

## Step 7: Test Access

The bot will now automatically access Drive files without authentication.

## Advantages

- ✅ No manual authentication required
- ✅ Works automatically on startup
- ✅ Can access shared team folders
- ✅ Single point of access control

## Disadvantages

- ❌ Less secure (service account key is powerful)
- ❌ All users see the same files
- ❌ Can't access personal user drives
- ❌ Requires manual file/folder sharing
- ❌ Service account keys need careful management

## For Production

- Store service account key in secure secret management (AWS Secrets Manager, etc.)
- Use specific Drive folder IDs for access control
- Implement proper key rotation
- Monitor service account usage in Google Cloud Console
