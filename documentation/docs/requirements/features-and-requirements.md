# Features and Requirements

## Functional Requirements
- The user can ask questions and receive documentation related to the question
- The chatbot is able to suggest followup questions based on user response to increase clarity
- User can upload documentation
- The bot can connect the user asking the question with people who wrote the documentation/feature they’re asking about
- Chatbot can create guides for user based on documentation
- Visibility of progress for employee users should be able to be seen by manager users


## Nonfunctional Requirements
- This should be able to be used on a variety of different frontends and databases 
- It should be able to hold several different conversation threads and maintain confidentiality where necessary
- It should separate data for consumption on the basis of confidentiality
- It should keep information confidential and not leak it through the LLM
