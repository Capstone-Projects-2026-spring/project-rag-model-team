# Features and Requirements

## Functional Requirements
- The chatbot must allow the user to be able to ask questions and receive documentation related to the question
- The chatbot must be able to suggest followup questions based on user response to increase clarity
- The system must allow user can upload documentation
- The chatbot must be able connect the user asking the question with people who wrote the documentation/feature they’re asking about
- The chatbot must be able to create guides for user based on documentation
- Visibility of progress for employee users must be able to be seen by manager users


## Nonfunctional Requirements
- This system must be able to be used on a variety of different frontends and databases 
- It must be able to hold several different conversation threads and maintain confidentiality where necessary
- It must separate data for consumption on the basis of confidentiality
- It must keep information confidential and not leak it through the LLM
