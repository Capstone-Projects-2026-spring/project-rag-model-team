# Google Drive Integration Setup Guide

This guide walks you through connecting your Slack bot to Google Drive API.

## Prerequisites

- Node.js installed
- npm packages installed: `npm install`
- A Google Cloud project with Drive API enabled

## Step 1: Set Up Google Cloud Console

1. Go to [Google Cloud Console](https://console.cloud.google.com)
2. Create a new project or select an existing one
3. Enable the **Google Drive API**:
   - Search for "Google Drive API"
   - Click Enable
4. Create OAuth 2.0 credentials:
   - Go to Credentials → Create Credentials → OAuth 2.0 Client IDs
   - Choose "Web application"
   - Add authorized redirect URI: `http://localhost:3001/oauth2callback`
   - Download the credentials JSON file
5. Copy your `Client ID` and `Client Secret`

## Step 2: Configure Environment Variables

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

2. Update `.env` with your credentials:
   ```
   SLACK_BOT_TOKEN=xoxb-your-bot-token
   SLACK_APP_TOKEN=xapp-your-app-token
   GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
   GOOGLE_CLIENT_SECRET=your-client-secret
   PORT=3001
   SERVER_URL=http://localhost:3001
   ```

## Step 3: Configure Slack Bot Commands

In your Slack app settings:

1. Go to **Slash Commands**
2. Add these commands:
   - `/connect-drive` - Start Google Drive authentication
   - `/drive-files` - List files from Google Drive
   - `/disconnect-drive` - Disconnect Google Drive

3. For each command:
   - Request URL: `http://your-domain:3001/command` (for local testing, use ngrok)
   - Short Description: Provide meaningful descriptions

## Step 4: Run the Bot

```bash
npm start
```

The bot will start on two endpoints:
- **Slack Socket Mode**: Connects to Slack via websocket
- **Express Server**: Runs on `http://localhost:3001` for OAuth callbacks

## Step 5: Test the Integration

1. In your Slack workspace, type `/connect-drive`
2. Click the "Connect Google Drive" button
3. Authorize the app to access your Google Drive
4. You'll be redirected back with a success message
5. Now use `/drive-files` to list your Google Drive files

## File Structure

```
google_api/
├── db.js                 # Token storage (JSON file-based)
├── googleAuth.js         # OAuth setup and token exchange
├── driveService.js       # Google Drive API operations
├── routes.js             # Express routes for OAuth callbacks
└── slack.js              # Slack command handlers
```

## Troubleshooting

### "User not authenticated with Google Drive"
- User hasn't run `/connect-drive` yet
- Tokens may have expired - run `/connect-drive` again

### OAuth callback fails
- Check that `GOOGLE_REDIRECT_URI` matches your Slack app settings
- Ensure Express server is running on port 3001
- For production, use a public URL (consider ngrok for local testing)

### Commands not showing in Slack
- Verify slash commands are properly configured in Slack app settings
- Ensure request URLs point to your bot's Express server
- Check that bot has permissions to post messages

## For Production

1. Use a proper database instead of JSON file for tokens
2. Use environment-specific URLs (not localhost)
3. Set up HTTPS for OAuth callbacks
4. Use a service like ngrok or deploy to a server
5. Implement token refresh logic for long-lived apps
6. Add error logging and monitoring

## Security Notes

- Never commit `.env` file to version control
- Token storage should be encrypted in production
- Rotate OAuth credentials regularly
- Monitor Drive API usage in Google Cloud Console
